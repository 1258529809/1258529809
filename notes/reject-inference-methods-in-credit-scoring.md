> **我的核心理解**
>
> 本文研究的是：传统拒绝推断能否改善“仅用已放款客户训练的信用评分模型”。它没有证明逻辑回归胜过所有模型。不同方法依赖不同假设，实验中没有发现一种传统策略在各数据集和拒绝比例下都稳定、显著占优。
>
> 关键问题是：方法引入了什么可信信息、依赖什么假设，以及能否验证它对目标人群的改进。

## 1. 已经有借贷模型，为什么还需要研究拒绝推断？

模型在放款之前给所有申请人打分，但还款标签通常只来自已经放款的人。

```text
历史审批规则选择客户
        ↓
只有已放款客户产生可观察的还款结果
        ↓
用这些标签训练新模型
        ↓
新模型又用于所有未来申请人
```

例如，旧政策很少给自由职业者放款，模型就很少获得这类人的真实标签。新模型仍然能输出风险概率，但这个概率对该人群是否可靠，不能仅凭已有测试集证明。

拒绝推断的实际意义包括：

- 判断历史被拒绝类型的人群中，是否存在能够正常还款的客户；
- 评估扩大服务范围或改变审批规则后的预测可靠性；
- 判断额外补标签、加权等处理是否值得采用。

**旧模型一定错了**不是研究前提；真正的问题是某些判断缺乏直接验证。拒绝推断也不会凭空产生真实标签。

本文的贡献主要是把已有方法的隐含假设形式化，检查它们到底改变了什么，并审视实验能否支持实际应用。

## 2. 数据与符号：先避免和另一篇论文混用

| 符号 | 本文含义 |
|---|---|
| $x$ | 已记录的申请人特征 |
| $Y=1$ | 好客户，正常还款 |
| $Y=0$ | 坏客户 |
| $Z=\mathrm f$ | 已放款，financed |
| $Z=\mathrm{nf}$ | 未放款，non-financed |
| $F,NF$ | 已放款、未放款客户的索引集合 |
| $\mathcal T_{\mathrm f}$ | 已放款客户数据，包含 $x,y,z$ |
| $\mathcal T_{\mathrm{nf}}$ | 未放款客户数据，只观察到 $x,z$ |
| $\mathcal T$ | 全部观测数据 |
| $\mathcal T_c$ | 假设所有缺失标签都可获得时的完整数据 |
| $\theta$ | 还款模型 $p_\theta(y\mid x)$ 的参数 |
| $\varphi$ | 放款机制 $p_\varphi(z\mid x,y)$ 的参数 |
| $\gamma$ | 联合模型的总体参数 |

**与首页深度生成模型笔记的区别：**

- 本文的 $z$ 是放款状态；深度生成模型中的 $z$ 是连续潜变量。
- 本文 $y=1$ 为好客户；首页部分解释采用 $y=1$ 为违约客户。比较 AUC、概率和分类方向时必须统一编码。
- financed 与 accepted 并非完全同义：获批者可能没有最终签约放款，也可能存在人工干预。实际标签可见性取决于是否真正放款以及后续结果是否成熟。

本文把未放款者的还款结果作为缺失标签处理。从现实含义看，关心的是其若获得相关贷款时的还款表现；本文的统计建模并不自动解决所有反事实与合同差异问题。

## 3. 联合模型：为什么不只写还款概率？

原文公式（1）把还款模型与放款机制结合起来：

```math
p_\gamma(y,z\mid x)
=
p_{\varphi(\gamma)}(z\mid x,y)
p_{\theta(\gamma)}(y\mid x).
```

我最终关心的是 $p_\theta(y\mid x)$，但观测到哪些标签由 $z$ 决定。一般情况下，需要考虑选择过程与结果之间的关系。

一般参数 $\gamma$ 可以同时约束 $\theta$ 和 $\varphi$；不能一开始就默认两组参数能够独立优化。

---

## 4. 公式（2）：为什么未放款客户要“先求和，再取对数”？

观测数据对数似然为：

```math
\ell(\gamma;\mathcal T)
=
\sum_{i\in F}\log p_\gamma(y_i,\mathrm f\mid x_i)
+
\sum_{i\in NF}\log
\left[
\sum_{y=0}^{1}p_\gamma(y,\mathrm{nf}\mid x_i)
\right].
```

两类客户实际提供的信息不同：

- 已放款客户：$y_i$ 与 $z_i=\mathrm f$ 都知道，所以使用对应联合概率。
- 未放款客户：只知道 $z_i=\mathrm{nf}$，不知道 $y_i$，因此必须把两种互斥的还款结果相加。

```math
p_\gamma(\mathrm{nf}\mid x_i)
=
p_\gamma(0,\mathrm{nf}\mid x_i)
+
p_\gamma(1,\mathrm{nf}\mid x_i).
```

教学例子：两个联合概率分别为 $0.12$ 和 $0.18$，则观测到“未放款”的概率为 $0.30$，对数似然贡献为 $\log(0.30)$。

**不是** $\log(0.12)+\log(0.18)$。后一种写法是两个概率相乘后取对数，不是对同一个未知标签的两种可能进行边缘化。

## 5. 公式（3）：E 步如何计算未放款客户的概率标签？

用上一轮参数计算：

```math
q_i^{(s)}
=
P_{\gamma^{(s-1)}}(Y_i=1\mid x_i,Z_i=\mathrm{nf})
=
\frac{
p_{\gamma^{(s-1)}}(1,\mathrm{nf}\mid x_i)
}{
\sum_{y=0}^{1}p_{\gamma^{(s-1)}}(y,\mathrm{nf}\mid x_i)
}.
```

这里用 $q_i^{(s)}$ 代替原文容易与真实标签混淆的 $y_i^{(s)}$，表示好客户的后验概率。

沿用前例：

```math
q_i^{(s)}=\frac{0.18}{0.12+0.18}=0.6.
```

这是好客户概率 $0.6$、坏客户概率 $0.4$，并没有确定真实标签。

进一步展开：

```math
q_i^{(s)}
=
\frac{
p_{\varphi_{\mathrm{old}}}(\mathrm{nf}\mid x_i,1)
p_{\theta_{\mathrm{old}}}(1\mid x_i)
}{
\sum_{y=0}^{1}
p_{\varphi_{\mathrm{old}}}(\mathrm{nf}\mid x_i,y)
p_{\theta_{\mathrm{old}}}(y\mid x_i)
}.
```

**一般情况下，不能忽略“此人未放款”这条信息，直接拿 $p_\theta(1\mid x_i)$ 替代。**只有在相应条件下，例如 MAR，放款机制才会在这个比值中抵消。

## 6. 公式（4）：完整似然、条件期望与 M 步

如果所有标签都知道，完整数据对数似然是：

```math
\ell_c(\gamma;\mathcal T_c)
=
\sum_{i=1}^{n}\log p_\gamma(y_i,z_i\mid x_i).
```

未放款客户的真实 $y_i$ 不知道，所以 EM 对完整对数似然取条件期望：

```math
\begin{aligned}
Q(\gamma\mid\gamma^{(s-1)})
={}&
\sum_{i\in F}\log p_\gamma(y_i,\mathrm f\mid x_i)\\
&+\sum_{i\in NF}
\left[
q_i^{(s)}\log p_\gamma(1,\mathrm{nf}\mid x_i)
+
(1-q_i^{(s)})\log p_\gamma(0,\mathrm{nf}\mid x_i)
\right].
\end{aligned}
```

M 步更新：

```math
\gamma^{(s)}
=
\arg\max_\gamma Q(\gamma\mid\gamma^{(s-1)}).
```

最大化时，E 步算出的 $q_i^{(s)}$ 固定，变化的是候选参数 $\gamma$。然后再用新参数重新计算概率。

| 对象 | 对缺失标签的处理 |
|---|---|
| 观测似然 $\ell$ | 对联合概率求和，再取对数 |
| EM 的 $Q$ 函数 | 对完整对数似然按旧参数下的后验概率加权 |

**校正记录：**我们读到的公式（4）后展开式，对两种 $y$ 都写成同一个 $y_i^{(s)}$ 权重；若该符号按公式（3）表示好客户概率，那么权重应分别为 $q_i^{(s)}$ 与 $1-q_i^{(s)}$。这里使用按条件期望定义展开的写法，不沿用该记号疏漏。

EM 是计算估计量的方法，不会自动保证模型可识别、估计真实或达到全局最优。

## 7. MCAR、MAR、MNAR：我最容易误解的地方

### 7.1 三种机制

| 机制 | 本文的表达 | 直觉 |
|---|---|---|
| MCAR | $p(z\mid x,y)=p(z)$ | 放款既不依赖特征，也不依赖还款结果 |
| MAR | $p(z\mid x,y)=p(z\mid x)$ | 给定已记录特征后，放款不再额外依赖还款结果 |
| MNAR | 一般不能去掉条件中的 $y$ | 给定已记录特征后，放款与还款结果仍有关 |

MCAR、MAR 是对更一般选择模型施加的限制。严格说，满足 MAR 的机制就不应同时称为 MNAR；原文“对 MNAR 的限制”是在从一般模型向特殊情况收缩。

### 7.2 早餐问卷的类比

设 $x$ 是性别，$y$ 是早餐量。女生更容易不填写早餐量，**单凭这一点不能判定 MAR**。还必须假设：

> 在相同性别内部，吃得多或少，不再影响填写概率。

教学例子：女生无论早餐量多少，都有 40% 的概率不填；男生无论早餐量多少，都有 10% 的概率不填。这符合以性别为已观测条件的 MAR。

如果同为女生，吃得越多越不愿填写，那么缺失仍依赖 $y$，不满足上述 MAR。

### 7.3 信贷中的对应关系

| 问卷 | 信贷 |
|---|---|
| 性别等已观测条件 | 收入、负债等已记录特征 $x$ |
| 早餐量 | 还款结果 $y$ |
| 是否填写 | 是否放款、从而能否观察还款结果 |

教学例子：

| 收入 | 好客户放款概率 | 坏客户放款概率 |
|---|---:|---:|
| 高收入 | 80% | 80% |
| 低收入 | 20% | 20% |

放款概率依赖收入，但固定收入后不依赖好坏标签：

```math
p(\mathrm f\mid x,Y=1)
=
p(\mathrm f\mid x,Y=0)
=
p(\mathrm f\mid x).
```

银行不需要预先知道未来标签；这是对数据分布中条件独立关系的描述。

### 7.4 确定性阈值也可以是 MAR

若规则仅由已记录的 $x$ 决定：

```math
Z=\mathrm f
\quad\Longleftrightarrow\quad
s(x)>c,
```

则固定 $x$ 后，放款决定已经确定，再知道 $y$ 不会改变它。MAR 不要求真的随机抽签。

**但 MAR 不等于覆盖充分。**若某些 $x$ 永远不放款，那里没有标签。对这些区域的预测依赖额外的模型与外推假设；不能因为满足 MAR 就声称数据已经验证这些区域。

### 7.5 人工审批为何可能产生 MNAR？

若审批人员使用了未录入模型的材料 $\tilde x$，这些材料影响放款，并且给定 $x$ 后仍与还款结果有关，就可能导致：

```math
p(z\mid x,y)\ne p(z\mid x).
```

“存在未记录变量”本身不足以证明 MNAR。关键是它与选择及结果的条件关联。机制也依赖我们究竟把哪些变量记录为 $x$。

## 8. 公式（5）：联合概率怎么变成放款概率？

我最初的问题是：

> MAR 明明只说 $p(z\mid x,y)=p(z\mid x)$，为什么似然中的 $p(y,\mathrm{nf}\mid x)$ 会消失一个 $y$？

答案有两步：先分解联合概率，再对缺失标签求和。

MAR 下：

```math
p_\gamma(y,z\mid x)
=
p_\theta(y\mid x)p_\varphi(z\mid x).
```

对未放款客户：

```math
\begin{aligned}
\sum_{y=0}^{1}p_\gamma(y,\mathrm{nf}\mid x)
&=
p_\varphi(\mathrm{nf}\mid x)
\sum_{y=0}^{1}p_\theta(y\mid x)\\
&=p_\varphi(\mathrm{nf}\mid x).
\end{aligned}
```

对已放款客户，标签已知，不求和：

```math
\log p_\gamma(y_i,\mathrm f\mid x_i)
=
\log p_\theta(y_i\mid x_i)
+
\log p_\varphi(\mathrm f\mid x_i).
```

因此：

```math
\boxed{
\ell(\gamma;\mathcal T)
=
\underbrace{\sum_{i\in F}\log p_\theta(y_i\mid x_i)}
_{\ell(\theta;\mathcal T_{\mathrm f})}
+
\underbrace{\sum_{i=1}^{n}\log p_\varphi(z_i\mid x_i)}
_{\text{所有人的放款状态}}.
}
```

再加上两组参数能够分别变化，即本文所用的参数可忽略性条件，优化 $\theta$ 就只需要第一项。

**MAR 与参数可分离是两个条件。**“可忽略”在更一般缺失数据理论中还有完整定义，这里沿用本文的建模语境，不能把参数可分离本身当成一般意义上的全部可忽略性条件。

## 9. 模型选择：为什么测试集仍不能解决问题？

### 9.1 全体申请人和已放款测试集不是同一个目标

公式（6）的测试错误率是：

```math
\operatorname{Error}(\mathcal T^{\mathrm{test}})
=
\frac1{|\mathcal T^{\mathrm{test}}|}
\sum_{i\in\mathcal T^{\mathrm{test}}}
\mathbb I(\hat y_i\ne y_i).
```

目标人群的分布满足公式（7）：

```math
p(y\mid x)
=
p(y\mid x,\mathrm f)p(\mathrm f\mid x)
+
p(y\mid x,\mathrm{nf})p(\mathrm{nf}\mid x).
```

实际却缺少未放款者的真实标签，因此无法直接评价第二类人的结果。

**可以计算已放款测试集的错误率，但不能自动把它当作全体申请人的错误率。**文章对公式（6）“不可计算”的讨论，应理解为目标总体测试集不可获得，不是任何错误率都算不出来。

在已放款数据内部随机切分训练集与测试集，两部分仍受同一个旧政策筛选。

### 9.2 BIC 为什么又说可以比较？

完整指定候选联合模型后，可考虑公式（8）：

```math
\mathrm{BIC}
=
-2\ell(\hat\gamma;\mathcal T)
+
\dim(\Gamma)\log n.
```

它使用观测似然，不要求补齐真实缺失标签。但必须有明确、可比较的联合模型，并考虑可识别性及适用的正则条件。

不能拿不同方法在不同伪标签数据上得到的训练似然直接做公平比较。BIC 也不会凭空识别真实 MNAR 机制，或保证选择的模型在被拒绝人群上预测最好。

## 10. 六种拒绝推断方法总览

| 策略 | 方法 | 新增处理 | 主要结论 |
|---|---|---|---|
| 1 | Ignoring non-financed clients | 只用已放款标签 | 满足条件时是一致估计 |
| 2 | Fuzzy Augmentation | 用原模型概率作软标签 | 在本文设置下等价于 1 |
| 3 | Reclassification | 概率变成 0/1 硬标签 | 一般不一致，可能使概率过于极端 |
| 4 | Augmentation / Re-weighting | 按放款概率倒数加权 | 面向模型设定错误，需要覆盖与准确权重 |
| 5 | Twins | 线性组合还款、放款两个 logit | 在本文设置下等价于 1 |
| 6 | Parcelling | 人为提高未放款者风险再补软标签 | 针对特定 MNAR 判断，依赖外部假设 |

下面的等价性讨论以相同模型族、相同训练数据、无额外正则化的精确最大化为背景。唯一性、有限 MLE 存在等条件也需要注意；实际软件的早停、惩罚与数值误差可能使输出不同。

## 11. 策略一：只用已放款客户

```math
\hat\theta_{\mathrm f}
=
\arg\max_\theta
\sum_{i\in F}\log p_\theta(y_i\mid x_i).
```

在 MAR、参数可忽略、模型正确设定，以及所需可识别性和常规估计条件下，它能一致估计还款模型。

这里“一致”是样本增大时趋近目标，不等于有限样本无偏，也不保证每次实验分数最高。完全缺少覆盖的区域不能靠 MAR 本身进行非参数识别。

## 12. 策略二：Fuzzy Augmentation 为什么最终不变？

记 $\pi_i(\theta)=p_\theta(1\mid x_i)$。先拟合已放款客户，再生成软标签：

```math
q_i=\pi_i(\hat\theta_{\mathrm f}),\qquad i\in NF.
```

重新训练目标为：

```math
\begin{aligned}
Q(\theta)
={}&\ell_{\mathrm f}(\theta)\\
&+\sum_{i\in NF}
\left[q_i\log\pi_i(\theta)
+(1-q_i)\log(1-\pi_i(\theta))\right],
\end{aligned}
```

其中：

```math
\ell_{\mathrm f}(\theta)
=
\sum_{i\in F}
[y_i\log\pi_i(\theta)+(1-y_i)\log(1-\pi_i(\theta))].
```

对于固定软标签 $q$，令：

```math
g(p)=q\log p+(1-q)\log(1-p).
```

则：

```math
g'(p)=\frac{q-p}{p(1-p)}.
```

在 $0<q<1$ 时，最大值在 $p=q$ 取得。因此旧参数：

1. 已经最大化真实标签部分；
2. 对每个未放款客户又恰好满足 $\pi_i(\hat\theta_{\mathrm f})=q_i$，分别最大化软标签部分。

所以旧参数仍然是整体最大化解。若解唯一：

```math
\boxed{\hat\theta^{(1)}=\hat\theta_{\mathrm f}}.
```

我的直觉：**让模型去拟合自己原先的概率判断，并没有引入新的目标。**

这不是把二元变量真的设为 0.7；它等价于对标签 1、0 分别赋予 0.7、0.3 的权重。

“不改变原模型”的代数结论不依赖真实世界一定为 MAR；但原模型是否可靠、是否一致，仍需另行检查假设。

## 13. 策略三：Reclassification 为什么会变得过于自信？

把概率转为 MAP 硬标签：

```math
\hat y_i
=
\arg\max_{y\in\{0,1\}}
p_{\hat\theta_{\mathrm f}}(y\mid x_i)
=
\begin{cases}
1,&\pi_i(\hat\theta_{\mathrm f})>0.5,\\
0,&\pi_i(\hat\theta_{\mathrm f})<0.5.
\end{cases}
```

等于 0.5 时需要约定平局处理。目标为：

```math
\ell_{\mathrm f}(\theta)
+
\sum_{i\in NF}
[\hat y_i\log\pi_i(\theta)
+(1-\hat y_i)\log(1-\pi_i(\theta))].
```

| 初始预测 | 软标签贡献 | 硬标签贡献 |
|---|---|---|
| 0.7 | $0.7\log p+0.3\log(1-p)$，最优在 0.7 | $\log p$，推动 $p$ 接近 1 |
| 0.4 | $0.4\log p+0.6\log(1-p)$，最优在 0.4 | $\log(1-p)$，推动 $p$ 接近 0 |

实际参数更新还受其他样本制约，不保证每个人的预测都单调变得极端；但这解释了文中“边界变陡”的机制。

一种变体只更新一次，另一种交替进行“硬分类—重新拟合”。它对应 Classification-EM，一般没有标准观测似然 MLE 的一致性保证。

**参数或概率有偏，不等于 Gini 必然明显下降。**只要排序大致保持，区分指标就可能接近。

实验中模拟放款的阈值 0.3 与 MAP 分类阈值 0.5 是不同的：前者决定隐藏谁的标签，后者决定填什么标签。

## 14. 策略四：Augmentation 与公式（9）的推导

### 14.1 权重直觉

假设总体 A、B 两类各 1000 人，放款概率分别为 0.8 和 0.2，则预计获得 800、200 个标签。

使用倒数权重：

```math
800\times\frac1{0.8}=1000,\qquad
200\times\frac1{0.2}=1000.
```

难以获放款的人在标签数据中被低估，每个观察到的同类客户因此代表更多人。需要 MAR 才能合理地用同一 $x$ 下已放款者的还款规律代表该类人群。

### 14.2 从总体期望变成已放款客户的加权期望

目标是：

```math
J(\theta)=\mathbb E_{X,Y}[\log p_\theta(Y\mid X)].
```

由贝叶斯公式：

```math
p(x)=\frac{p(x\mid\mathrm f)p(\mathrm f)}{p(\mathrm f\mid x)}.
```

在 MAR 及 $p(\mathrm f\mid x)>0$ 等条件下：

```math
\begin{aligned}
J(\theta)
&=\sum_y\int\log p_\theta(y\mid x)p(y\mid x)p(x)\,\mathrm dx\\
&=p(\mathrm f)\sum_y\int
\frac{\log p_\theta(y\mid x)}{p(\mathrm f\mid x)}
p(y\mid x,\mathrm f)p(x\mid\mathrm f)\,\mathrm dx\\
&=p(\mathrm f)\,
\mathbb E_{X,Y\mid Z=\mathrm f}
\left[\frac{\log p_\theta(Y\mid X)}{p(\mathrm f\mid X)}\right].
\end{aligned}
```

令 $n_{\mathrm f}=|F|$，条件样本平均为：

```math
J(\theta)\approx
\frac{p(\mathrm f)}{n_{\mathrm f}}
\sum_{i\in F}
\frac{\log p_\theta(y_i\mid x_i)}
{p(\mathrm f\mid x_i)}.
```

去掉与 $\theta$ 无关的正常数后：

```math
\boxed{
\hat\theta_{\mathrm{aug}}
=
\arg\max_\theta
\sum_{i\in F}
w_i
[y_i\log\pi_i(\theta)+(1-y_i)\log(1-\pi_i(\theta))],
\quad
w_i=\frac1{p(\mathrm f\mid x_i)}.
}
```

**归一化校正：**对话中所读原文式（9）末行写成 $p(\mathrm f)/n$。若 $n$ 仍表示所有申请人数，按上述条件样本平均应是 $p(\mathrm f)/n_{\mathrm f}$；再以 $n_{\mathrm f}/n$ 估计 $p(\mathrm f)$，前置系数才近似 $1/n$。正常数不改变参数最大化解，但会影响作为总体期望估计的数值。这里记录推导上的记号问题，不宣称已经核实作者补充材料实现。

### 14.3 实际如何估计权重？

原文按初始评分分成通常 10 个等宽区间，用每组“已放款人数 / 全部申请人数”估计放款概率，再用倒数加权。

这是对个人放款概率的分组近似。若相同评分下仍有重要的选择差异，分箱比例未必等于真实 $p(\mathrm f\mid x)$。

### 14.4 为什么主要针对模型设定错误？

模型正确时，满足条件的未加权估计已经瞄准真实参数。模型错误时，只能寻找最佳近似：

```math
\theta^\star
=
\arg\max_\theta
\mathbb E_{\text{目标总体}}[\log p_\theta(Y\mid X)].
```

未加权拟合按已放款人群分布折中；正确加权按目标总体分布折中。**加权不能修复模型形式本身，只改变最佳近似所对应的人群。**

### 14.5 覆盖与方差限制

- $p(\mathrm f\mid x)=0$：没有同类已放款者可代表该区域，倒数权重不存在。
- 概率很小：权重很大，少数样本可能主导拟合。
- 概率必须估计：又引入估计偏差与方差。
- 严格正概率只是基本条件，**本身不足以保证有限方差**；还需控制相关加权量的矩。

## 15. 策略五：Twins 为什么仍然回到原模型？

令 $\tilde x=(1,x^\top)^\top$，先建立两个线性评分：

```math
s_y(x)=\tilde x^\top\hat\theta_{\mathrm f},
\qquad
s_z(x)=\tilde x^\top\hat\varphi.
```

第一个用已放款标签预测还款，第二个用全部申请人的放款状态预测是否放款。

第三个逻辑回归在已放款客户上训练：

```math
P(Y=1\mid s_y,s_z)
=
\sigma(a+b\,s_y+c\,s_z).
```

这里使用的是 **logit 线性评分，不是 sigmoid 后的概率**。

展开：

```math
a+b\,s_y+c\,s_z
=
\tilde x^\top
(ae_0+b\hat\theta_{\mathrm f}+c\hat\varphi)
=
\tilde x^\top\beta,
```

其中 $e_0=(1,0,\ldots,0)^\top$。

证明等价需要两个条件：

1. 组合产生的 $\beta$ 仍属于原来的逻辑回归系数空间，不能超过原模型在相同数据上的全局最大似然值；
2. 取 $a=0,b=1,c=0$ 就能恢复 $\hat\theta_{\mathrm f}$，所以至少可以达到该最大值。

唯一最优系数存在时：

```math
\hat\theta_{\mathrm{twins}}=\hat\theta_{\mathrm f}.
```

相等的是换回原始特征后的模型系数，第三层的 $(a,b,c)$ 不一定唯一。最后再做模糊增广也不会改变结果。

仅说“两个线性模型组合仍然线性”还不够，**还必须说明候选集合包含原模型的最优解**。若使用概率特征、非线性组合、不同数据或不同惩罚，不能直接套用该证明。

## 16. 策略六：Parcelling 如何改变软标签？

先估计已放款客户的坏客户概率：

```math
r_i=p_{\hat\theta_{\mathrm f}}(0\mid x_i,\mathrm f).
```

按评分区间指定审慎因子 $\epsilon_{k(x_i)}$，原文写为：

```math
\hat p(0\mid x_i,\mathrm{nf})
\propto
\epsilon_{k(x_i)}r_i.
```

随后用调整后的坏客户概率 $\tilde r_i$ 生成好客户软标签：

```math
q_i=1-\tilde r_i,
```

再优化与模糊增广形式相同的加权标签目标。

**原文这里是正比号，不是完整的概率转换定义。**具体实现需要保证概率有效；不能无条件把它写成等号。

教学例子：若某实现采用直接乘法且结果仍在合法区间，$r_i=0.2,\epsilon_k=1.5$ 得到 $\tilde r_i=0.3$、$q_i=0.7$。原模型好客户概率为 0.8，现在被要求拟合 0.7，所以模型可能改变。

其额外假设是：

```math
p(0\mid x,\mathrm{nf})>p(0\mid x,\mathrm f).
```

**MNAR 本身不规定这个方向。**“未放款客户更差”以及“差多少”，是另加的判断，而非 MNAR 的定义。

作者用审批人员掌握未记录材料来解释这一差异。但仅凭现有观测数据，无法确定审慎因子是否正确。模型变化来自额外判断，变化是否更好取决于判断是否可信。

还要区别“同一评分区间”与“完全相同 $x$”：前者是实现中的分组近似，不自动等于后者。

## 17. 模拟实验：为什么逻辑回归在这里设定正确？

作者生成 20 个训练集，每个 10,000 人；一个测试集，100,000 人。在 $d=8$ 的实验中：

```math
Y\sim\operatorname{Bernoulli}(1/2),
\qquad
X\mid Y=y\sim\mathcal N(\mu_y,2I),
\quad
\mu_0=\mathbf0,\ \mu_1=\mathbf1.
```

两类协方差相同；**给定类别后**各特征独立，不应据此称混合总体中的特征也独立。

由贝叶斯公式，真实 logit 为：

```math
\begin{aligned}
\log\frac{P(Y=1\mid x)}{P(Y=0\mid x)}
&=-\frac14\|x-\mathbf1\|^2+\frac14\|x\|^2\\
&=\frac12\sum_{j=1}^{d}x_j-\frac d4.
\end{aligned}
```

当 $d=8$：

```math
P(Y=1\mid x)
=
\sigma\left(-2+\frac12\sum_{j=1}^{8}x_j\right).
```

因此真实条件概率就在逻辑回归模型族中。

作者先在完整训练集上拟合评分，再逐渐提高 cut：

```math
Z_i=\mathrm f
\Longleftrightarrow
p_{\hat\theta}(1\mid x_i)>\mathrm{cut}.
```

未放款样本只隐藏标签，特征仍保留。固定已拟合的规则后，选择只依赖 $x$，作者将其作为 MAR、可忽略情形。阈值筛选仍可能破坏全空间的正概率覆盖，尤其会影响重要性加权。

作者文字报告：

- 策略 1、2、5 结果相同；
- 仅用已放款客户与重新分类的 Gini 差异不显著；
- 阈值提高时，前者优于增广和 Parcelling；
- 高斯生成式模型在标签较少时显示优势。

在另一组模拟中，两类使用不同协方差矩阵，真实 logit 一般出现二次项，普通线性 logit 模型发生设定错误，而相应高斯类别条件模型仍正确。作者报告生成式模型优势更明显。

这些是作者实验报告，不是本次独立运行得到的结果。

## 18. 高斯混合、生成式模型与真实数据结果

### 18.1 为什么真实数据不用高斯混合？

**高斯混合模型本身就是生成式模型。**这里是具体分布形式的变化，不是从高斯模型“转向生成式”。

| 数据 | 主要表示 | 本文使用的生成式形式 |
|---|---|---|
| 模拟数据 | 连续正态特征 | 高斯类别条件／混合模型 |
| 真实业务数据 | 连续变量分箱、类别合并后的类别特征 | 多项分布生成式模型 |

两者都利用：

```math
p(x,y)=p(y)p(x\mid y),
\qquad
p(y\mid x)=\frac{p(y)p(x\mid y)}{\sum_{y'}p(y')p(x\mid y')}.
```

未放款客户也可通过：

```math
p(x)=\sum_y p(y)p(x\mid y)
```

参与拟合。但分类特征适合考虑类别分布，不等于具体多项分布模型一定设定正确；没有完整核查补充材料前，也不应凭空给它添加朴素条件独立等实现细节。

### 18.2 为什么无标签数据在生成式模型中有用？

在仅建模条件分布的 MAR 情形中：

```math
\sum_y p_\theta(y\mid x)=1.
```

对缺失标签求和后，不再含还款参数信息。而生成式模型的：

```math
\sum_y p_\eta(x,y)=p_\eta(x)
```

通常仍依赖模型参数 $\eta$，所以无标签特征能约束生成模型。代价是增加了分布建模假设。

### 18.3 为什么真实数据低阈值处效果较差？

作者提出两个可能原因：

- 生成式模型作了更多分布假设，可能有更大的模型设定误差；
- 特征是专为逻辑回归评分卡设计的，对逻辑回归更有利。

这些是作者的解释，不是实验单独识别出的因果贡献。低阈值时标签多，利用无标签数据的额外收益较小；标签减少时该优势可能更明显。这是理解结果的取舍框架，不能视为普遍定律。

### 18.4 三个业务数据集的结果意味着什么？

作者比较消费电子、体育公司与网站客户三个业务数据集。基于文字报告：

- 所有逻辑回归策略在没有模拟拒绝的起点表现相同；
- 低阈值下结果接近，阈值升高时表现恶化；
- 约到 50% 放款率停止，原因包括训练集坏客户过少、某些类别仅在测试集中出现等计算问题；
- 生成式模型在高阈值处显示一定潜力；
- 没有方法在三个业务数据集上都显著、统一优于已放款逻辑回归基线。

50% 是实验停止位置，不是业务建议。某个点曲线稍高不等于稳定显著优势。未在本笔记复述未经原图核验的颜色、误差棒或精确坐标。

## 19. Gini 怎么计算，为什么使用它？

本文 $Y=1$ 为好客户，使用越高越可能正常还款的评分 $s$：

```math
\mathrm{AUC}
=
P(s(X^+)>s(X^-))
+\frac12P(s(X^+)=s(X^-)),
\qquad
\boxed{\mathrm{Gini}=2\mathrm{AUC}-1}.
```

经验计算：

```math
\mathrm{AUC}
=
\frac1{n_1n_0}
\sum_{i:y_i=1}\sum_{j:y_j=0}
\left[\mathbb I(s_i>s_j)+\frac12\mathbb I(s_i=s_j)\right].
```

教学例子：好客户评分 0.9、0.4；坏客户评分 0.6、0.2。四对中三对正确：

```math
\mathrm{AUC}=3/4=0.75,\qquad
\mathrm{Gini}=0.5.
```

| Gini | 含义 |
|---:|---|
| 1 | 所有好客户都排在坏客户之前 |
| 0 | 与随机排序相当 |
| 小于 0 | 总体方向相反，需先检查标签与评分方向 |

使用原因：信用评分关心排序；不必固定单一分类阈值；相比准确率，更能体现模型是否区分了好坏客户。若把所有客户都预测成占比 95% 的好客户，准确率可能很高，但常数评分的 Gini 为 0。

**Gini 不直接衡量概率校准、利润或政策效果。**严格单调变换评分可保持 AUC，却改变概率数值。它也不免疫于测试人群选择：已放款人群与全体申请人的条件分布不同，AUC 可能不同。

## 20. 测试集都是已放款客户，为什么还关心拒绝者？

我最初混淆了“预测服务谁”和“有谁可用于验证”。

| 问题 | 已放款测试集能否直接回答 |
|---|---|
| 对类似历史已放款客户的区分能力 | 可以评估 |
| 对历史被拒绝类型客户的预测是否正确 | 通常不能 |
| 改变放款政策后对全体申请人的效果 | 不能直接保证 |

- **模拟实验**：所有标签由作者生成，隐藏训练标签后仍有完整测试真值。
- **真实数据实验**：从历史已放款者中模拟拒绝，拥有被隐藏的真值；但这群人原本经过历史筛选，不等于真正被拒绝者。
- **现实部署**：真正未放款者没有同一贷款的已观察还款标签。

拒绝推断尝试改善目标总体预测，但不会自动提供公平验证所需的标签。这是论文批评经验结论容易相互矛盾的核心原因。

## 21. 我读完后如何准确概括结论？

### 21.1 不是“没有模型比逻辑回归强”

正确基准是：

> 仅使用已放款客户训练的逻辑回归。

正确范围是：

> 本文分析的传统拒绝推断策略，在所研究条件和实验中，没有显示相对于该基准的稳定、显著优势。

生成式模型在部分实验条件下就可能优于基于逻辑回归的方法。不能把结论扩展成所有模型、所有场景的排名。

### 21.2 为什么“模型没变”也值得研究？

模糊增广和 Twins 看上去增加了信息处理，但在本文设置下没有改变最终模型。证明这种等价性可以避免无效复杂度。

重新分类虽然改变了模型，却可能引入偏差；加权和 Parcelling 有针对性，但需要额外信息。研究的价值是区分这些情况，而不只是再提出一个算法。

### 21.3 局部与全局模型的范围

作者将逻辑回归等直接依赖条件分布的模型称为局部模型，并讨论其他依赖特征分布的模型。这是本文语境，不能简单等同于线性／非线性。

不要把论文对某类模型的结论机械套用到全部树模型、神经网络或生成式方法。具体是否受选择偏差影响，还要看目标函数、模型假设、训练方式、覆盖和目标人群。

### 21.4 与上一篇深度生成模型论文的联系

上一篇笔记研究：无标签 ELBO 如何让 rejected 数据产生训练梯度。本篇追问：这种利用依赖哪些假设，是否能证明目标人群上的改进？

二者并不矛盾：

```text
无标签数据能够产生梯度
        ≠
无标签数据必然改善泛化
        ≠
已放款测试集改善就证明真正拒绝者预测正确
```

比较两篇论文时，需要统一标签方向，区分潜变量与放款状态，并核查目标人群和评估机制。

## 22. 我的关键疑问与最终理解

| 当时的问题 | 最终理解 |
|---|---|
| 公式（2）为什么先求和？ | 缺失的同一个标签有两种互斥可能，先边缘化 |
| 公式（3）算出了真实标签吗？ | 没有，只是当前模型下的后验概率 |
| 公式（4）为什么用 0.6、0.4？ | 对完整对数似然取条件期望 |
| MAR 为什么还能按收入筛人？ | 允许依赖 $x$，要求给定 $x$ 后不再依赖 $y$ |
| 确定性阈值还算随机缺失吗？ | 可以；MAR 是条件独立限制，不要求实际抽签 |
| $p(y,\mathrm{nf}\mid x)$ 怎么变成 $p(\mathrm{nf}\mid x)$？ | MAR 下分解，再对缺失 $y$ 求和为 1 |
| Fuzzy 为什么不变？ | 旧模型同时最大化真实标签目标和自己生成的软标签目标 |
| Reclassification 为什么可能有偏？ | 把概率判断变成确定标签，推动更极端预测 |
| 加权为什么用倒数？ | 让较少被观察到的同类客户代表更多总体成员 |
| Twins 为什么不改进？ | 候选组合是原系数空间的子集，又包含原最大化解 |
| Parcelling 新增了什么？ | 人工指定未放款者更高风险的幅度 |
| 高斯混合与生成式是否对立？ | 高斯混合就是生成式模型的一种 |
| 生成式模型为什么真实数据较差？ | 更多分布假设可能错误，且特征专为逻辑回归加工 |
| Gini 高是否代表概率准确？ | 不代表；它评价排序 |
| 已放款测试集能评价拒绝者吗？ | 不能直接，需要目标人群真值或额外识别假设 |
| 已有银行模型为何还研究？ | 研究选择后数据支持了哪些判断，额外处理是否有效 |

## 23. 理解校正与后续可验证的问题

### 23.1 本次整理保留的边界

- MAR 不自动保证正概率覆盖、全空间识别或有限样本无偏。
- “未记录信息”不自动意味着 MNAR，“MNAR”也不自动意味着拒绝者更差。
- 软标签不是实际的二元观测，EM 使用的是期望对数似然。
- Fuzzy 与 Twins 的精确等价需要对应优化设置；最优参数唯一性需要单独说明。
- 正概率不是有限方差的充分条件。
- Gini 是 $2\mathrm{AUC}-1$，更准确地说是仿射关系，不是简单正比例。
- 多项分布模型适合考虑类别数据，不保证设定正确，也未在本次核实其全部结构。
- “无显著差异”不是证明模型等价；“没有稳定优势”不是不可能改善的定理。
- 参数可分离不等于无需其他条件的一般可忽略性。
- 原文关于法国征信信息的说明属于论文当时的语境，不作为当前制度事实。

### 23.2 后续研究计划（尚未执行）

| 问题 | 可以做的验证 | 需要观察的证据 |
|---|---|---|
| Fuzzy 是否回到原解？ | 同一无惩罚逻辑回归，真实标签训练后生成软标签重训 | 参数与预测差异是否仅为数值误差 |
| CEM 是否过于自信？ | 在已知真概率的模拟数据上比较 soft/hard 标签 | 同时检查 AUC、log loss、Brier 与校准 |
| 加权何时有帮助？ | 交叉设置模型正确/错误、随机选择/硬阈值，比较真实/估计权重 | 区分模型偏差、权重误差和覆盖不足 |
| 生成式模型收益来自哪里？ | 控制分布正确程度与标签比例 | 无标签收益是否被设定误差抵消 |
