## 一、基础：平稳、白噪声与协方差

弱平稳要求：均值不随 t 改变；二阶矩有限；协方差只依赖滞后 k：

$$\gamma_k=\operatorname{Cov}(X_t,X_{t-k}),\qquad \rho_k=\gamma_k/\gamma_0.$$

白噪声 $\epsilon_t\sim WN(0,\sigma^2)$ 满足均值为 0、方差为 $\sigma^2$、不同时期不相关；不一定独立，也不一定正态。弱平稳不自动推出严格平稳或遍历性。

例如 $X_t=a_0+a_1t+\epsilon_t$，若 $a_1\ne0$，均值依赖 t，故不平稳。一阶差分 $Z_t=X_t-X_{t-1}=a_1+\epsilon_t-\epsilon_{t-1}$：均值 $a_1$，$\gamma_Z(0)=2\sigma^2$，$\gamma_Z(\pm1)=-\sigma^2$，其余为 0，因此弱平稳。

线性过程 $X_t=\sum_j\psi_j\epsilon_{t-j}$ 在系数平方可和时可按均方收敛定义，且弱平稳。对因果表示、$k\ge0$：

$$\gamma_k=\sigma^2\sum_{j=0}^\infty\psi_j\psi_{j+k}.$$

注意白噪声仅不相关时不能直接断言线性过程严格平稳或遍历；需额外条件。

## 二、滞后算子和差分方程

$BX_t=X_{t-1}$，$B^jX_t=X_{t-j}$。若 $|a|<1$，$(1-aB)^{-1}=\sum_{j\ge0}a^jB^j$。

对齐次方程 $A(B)X_t=0$，设 $A(z)$ 有根 $z$。单根对应 $z^{-t}$；重数为 2 时对应 $z^{-t}$ 和 $tz^{-t}$。共轭根 $\rho e^{\pm i\lambda}$ 可合并为 $\rho^{-t}[C\cos(\lambda t)+D\sin(\lambda t)]$。

手写笔记 770 中 $A(z)=1-z+0.25z^2$ 的根 2 是二重根，第二项应有 $t$：$X_t=(C_1+C_2t)2^{-t}$。同页 $1+z^3$ 的复根为 $e^{\pm i\pi/3}$，另一个根为 $-1$。

## 三、AR：平稳解、Wold 和 Yule–Walker

$$X_t=c+\sum_{j=1}^p\phi_j X_{t-j}+\epsilon_t,\quad A(z)=1-\sum_{j=1}^p\phi_jz^j.$$

在通常的因果 AR 模型下，所有 AR 根严格在单位圆外，得到唯一因果平稳解。注意若允许依赖未来噪声，非因果平稳解的判定更宽，考试按课程的因果约定作答。

平稳均值 $\mu=c/(1-\sum\phi_j)$；令 $Y_t=X_t-\mu$，则 $Y_t=\sum\phi_jY_{t-j}+\epsilon_t$。中心化不改变协方差及 ACF。

因果 Wold 表示：$X_t-\mu=\sum_{j=0}^\infty\psi_j\epsilon_{t-j}$，$\psi_0=1$、$\psi_j=0$（$j<0$），且 $\psi_j=\sum_{i=1}^p\phi_i\psi_{j-i}$。所以 $\psi_1=\phi_1$，$\psi_2=\phi_1^2+\phi_2$。笔记 772 的求和下标和 $\psi_2$ 记法需按此修正：展开从 $j=0$ 到无穷，不是从 1 到 p。

AR(1) 在 $|a|<1$ 时：$\psi_j=a^j$，$\gamma_k=\sigma^2a^{|k|}/(1-a^2)$，$\rho_k=a^{|k|}$。

AR(2) 的 Yule–Walker 方程：$\gamma_k=\phi_1\gamma_{k-1}+\phi_2\gamma_{k-2}$（$k\ge1$，利用 $\gamma_{-k}=\gamma_k$），且 $\gamma_0=\phi_1\gamma_1+\phi_2\gamma_2+\sigma^2$。因此 $\rho_0=1$、$\rho_1=\phi_1/(1-\phi_2)$，$\rho_k=\phi_1\rho_{k-1}+\phi_2\rho_{k-2}$（$k\ge2$）。例如 $(\phi_1,\phi_2)=(1,-0.25)$ 时 $\rho_1=0.8,\rho_2=0.55$。

## 四、PACF 与行列式

将 $X_t$ 对过去 n 项作最佳线性预测，系数 $a_{n,1},\ldots,a_{n,n}$ 满足 $\Gamma_n\mathbf a_n=\boldsymbol\gamma_n$，其中 $\boldsymbol\gamma_n=(\gamma_1,\ldots,\gamma_n)^T$。最后一个系数 $a_{n,n}$ 是 n 阶 PACF。

$$a_{1,1}=\rho_1,\qquad a_{2,2}=\frac{\rho_2-\rho_1^2}{1-\rho_1^2}.$$

AR(p) 的 PACF 在 p 阶之后为零，$a_{p,p}=\phi_p$；一般 AR 的 ACF 拖尾。例：$X_t=X_{t-1}-0.3X_{t-2}+\epsilon_t$，$a_{1,1}=10/13$、$a_{2,2}=-0.3$、$a_{3,3}=0$（PPT 100）。

MA(1) $X_t=\epsilon_t+b\epsilon_{t-1}$：$\gamma_0=(1+b^2)\sigma^2,\gamma_1=b\sigma^2,\gamma_{k>1}=0$。约去矩阵中公共因子 $\sigma^2$，记标准化三对角矩阵行列式为 $D_n$，则 $D_0=1,D_1=1+b^2$，$D_n=(1+b^2)D_{n-1}-b^2D_{n-2}=1+b^2+\cdots+b^{2n}$。用克拉默法则得

$$a_{n,n}=\frac{(-1)^{n+1}b^n}{1+b^2+\cdots+b^{2n}}.$$

对 $0<|b|<1$，PACF 拖尾；$b=0$ 退化为白噪声。原始协方差矩阵的行列式还带 $(\sigma^2)^n$，计算系数时分子分母会约去。

## 五、MA 和 ARMA

MA(q)：$X_t=\sum_{j=0}^q b_j\epsilon_{t-j}$，$b_0=1$。有限 MA 总是弱平稳。对 $0\le k\le q$，$\gamma_k=\sigma^2\sum_{j=0}^{q-k}b_jb_{j+k}$；$k>q$ 时为 0，因此 ACF 在 q 阶后截尾。一般非退化 MA 的 PACF 拖尾。

MA 可逆：$C(z)=1+b_1z+\cdots+b_qz^q$ 的所有根严格在单位圆外，此时白噪声可用现在与过去的 $X$ 收敛表示。PPT 134：$1-1.3z+0.4z^2$ 的根为 1.25、2，可逆；$1-1.6z+0.6z^2$ 有根 1，不可逆。前一模型 $\gamma_0=2.85\sigma^2,\gamma_1=-1.82\sigma^2,\gamma_2=0.4\sigma^2$。

ARMA：$A(B)X_t=C(B)\epsilon_t$，因果平稳性看 AR 根，可逆性看 MA 根（约去共同因子后的表示）。$\psi_0=1$，$\psi_j=b_j+\sum_{i=1}^p\phi_i\psi_{j-i}$，超出范围的 $b_j$、负下标的 $\psi$ 为 0。例：$X_t=0.9X_{t-1}+\epsilon_t+0.5\epsilon_{t-1}$，$\psi_1=1.4$，$\psi_j=1.4(0.9)^{j-1}$（$j\ge1$）。一般非退化 ARMA 的 ACF、PACF 均拖尾。

## 六、谱密度（复习优先级待确认）

若谱分布有密度 $f$，$\gamma_k=\int_{-\pi}^{\pi}e^{ik\lambda}f(\lambda)d\lambda$。对于适当可和的线性滤波器：

$$f(\lambda)=\frac{\sigma^2}{2\pi}\left|\sum_j\psi_j e^{-ij\lambda}\right|^2.$$

实系数时指数使用正号得到同样的模平方；注意采用的 $2\pi$ 规范要前后一致。

### 导入、分解与指数平滑

```r
# 安装仅第一次；考试前确认已安装和可使用的包
library(readxl)
library(forecast)

df <- read_excel("你的文件.xlsx", range = "B1:M7")
# 笔记假设各行按年份、各列按月份排列；必须检查是否包含表头或非数值列
values <- as.vector(t(as.matrix(df[, 1:12])))
x <- ts(as.numeric(values), start = c(1973, 1), frequency = 12)
plot(x, xlab = "时间", ylab = "观测值")

t <- time(x)
fit <- lm(x ~ t)
abline(fit, col = "blue")
summary(fit)
# 二次趋势用 I(t^2)，曲线使用 lines 而不是 abline
fit2 <- lm(x ~ t + I(t^2))
lines(t, fitted(fit2), col = "red")
res <- residuals(fit)

# 加法分解：至少两个完整季节周期
parts <- decompose(x, type = "additive")
plot(parts)
# 水平+趋势+加法季节，h 表示预测步数
pred <- hw(x, seasonal = "additive", h = 12)
print(pred)
plot(pred)
```

笔记中的残差按月求均值也是一种季节因子估计：确认月份对齐、序列为整年且去趋势正确，最后应根据需要将季节因子中心化。`abline()` 用于直线；时序曲线用 `lines()`。

### 检验与模型计算

```r
acf(x, lag.max = 12)                  # 样本 ACF
pacf(x, lag.max = 12)                 # 样本 PACF
Box.test(x, lag = 12, type = "Ljung-Box")  # 原假设：至指定滞后无自相关
# 非拒绝原假设不等于证明独立或证明白噪声

ar <- c(1, -0.3)
ma <- c(-1.3, 0.4)
polyroot(c(1, -ar))                   # AR: 1 - phi_1 z - ...
ma_root <- polyroot(c(1, ma))         # MA: 1 + b_1 z + ...
all(Mod(ma_root) > 1 + 1e-8)        # 单位圆附近需考虑舍入误差

ARMAacf(ar = ar, lag.max = 12)       # 理论 ACF，含 rho_0
ARMAacf(ar = ar, lag.max = 12, pacf = TRUE)  # PACF 从第 1 阶起
c(1, ARMAtoMA(ar = ar, lag.max = 12)) # Wold psi_0,...,psi_12

library(astsa)
pi_coef <- ARMAtoAR(ma = ma, lag.max = 5)
print(pi_coef)                        # epsilon_t = X_t + sum(pi_j X_{t-j})
```

注意 `ARMAtoAR` 输出是白噪声写在左侧时的系数，移项写成 $X_t=\epsilon_t+\cdots$ 时变号。第一个 MA 模型的前 5 个逆系数为 1.3、1.29、1.157、0.9881、0.82173；此前聊天中给出的第 4、5 项有误。
